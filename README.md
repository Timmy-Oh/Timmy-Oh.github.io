# Timmy-Oh · 개인 개발자 페이지

[timmy-oh.github.io](https://timmy-oh.github.io/)에서 Python 자동화, Godot 게임 개발, 전략·서사에 관한 현재의 관심사를 소개합니다.

## 구성

- `index.html`: 한국어 중심의 반응형 단일 페이지. 스타일을 HTML 안에 포함합니다.
- `.nojekyll`: GitHub Pages에서 정적 파일을 그대로 게시합니다.

외부 폰트, JavaScript, 분석 도구를 사용하지 않습니다. 공개 링크는 [GitHub 프로필](https://github.com/Timmy-Oh)과 이 홈페이지에 한정합니다.

## 수정과 확인

`index.html`을 브라우저에서 열어 확인할 수 있습니다. 소개 문구와 관심사는 HTML 본문에서, 색상과 화면 크기에 따른 배치는 `<style>`에서 수정합니다. 게시 전에 모바일 폭과 키보드 탐색을 확인합니다.

## 지난 자료

과거 NLP·머신러닝 실험과 학습 기록은 재현성과 출처를 검토하기 위해 공개 목록에서 정리했습니다. 검토를 마친 작업은 실행 방법과 한계를 함께 정리한 뒤 소개합니다.

이 저장소는 개인 소개와 공개 기록을 위한 공간입니다.
